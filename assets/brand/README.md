# Бренд Radar

Логотип: вордмарк **`radar_`** (вариант C, выбран 2026-10-09). Буквы моноширинные, подчёркивание-курсор оранжевое.
Обоснование выбора и история — в [`docs/tasks/logo.md`](../../docs/tasks/logo.md).

## Файлы

| Файл | Где использовать |
|---|---|
| `radar-wordmark-on-dark.svg` | на тёмном фоне (README в тёмной теме, сайт, GIF) |
| `radar-wordmark-on-light.svg` | на светлом фоне |
| `radar-wordmark-mono-black.svg` / `-white.svg` | одноцветная печать, наклейки, ч/б |
| `radar-icon.svg` | иконка приложения `Radar.app` (1024×1024 с полем 100 px, как в шаблоне macOS) |
| `radar-favicon.svg` | favicon, аватар организации (без поля) |

Готовые растры лежат не здесь, а там, где их используют: `assets/icon.{svg,png,icns}` (встраивается в бинарник, `src/notify.rs`),
`docs/icon.png`, `docs/social-preview.png`, а для сайта копии в `docs/brand/`.

## Правила

- **Цвета:** акцент `#f59e0b` на тёмном и `#d97706` на светлом фоне; текст `#e6e9ef` на тёмном и `#1b1e24` на светлом. Фон иконки: градиент `#171d27 → #0b0e13`.
- **Поля:** вокруг вордмарка не меньше высоты буквы `r`. Высота вордмарка не меньше 20 px.
- **Курсор всегда оранжевый** (кроме одноцветных версий) и стоит под строкой, как подчёркивание в терминале. Нельзя заменять его другим символом, красить в другие цвета, анимировать мигание в статичных местах (README, превью).
- **Монограмма `r_`** — только для квадратных мест (иконка, favicon, аватар). Не растягивать, не добавлять рамки и тени.
- **Нельзя:** менять шрифт, перекрашивать буквы в акцентный цвет, ставить вордмарк на пёстрый фон без плашки.

## Пересборка

```sh
pip install fonttools playwright pillow && playwright install chromium
python3 assets/brand/build.py     # SVG; копии для сайта кладёт в docs/brand/
python3 assets/brand/render.py    # assets/icon.*, docs/icon.png, docs/social-preview.png (.icns собирается без iconutil)
```

Шрифт — DejaVu Sans Mono Bold (свободная лицензия, допускает встраивание контуров); в SVG он не подключается, буквы переведены в кривые.
