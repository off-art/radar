Много AI-агентов.
Одно окно. Many AI agents.
One window.

Radar показывает, кто из агентов работает, кто закончил и кому нужен ваш ответ. Один бинарник на Rust, прямо в терминале. Radar shows which agents are working, which are done and which need your answer. A single Rust binary, right in your terminal.

Что внутриWhat you get

Всё, чтобы вести несколько агентов сразу и не терять нить.Everything you need to drive several agents at once without losing the thread.

01 ●

Статусы в реальном времениReal-time statuses

Работает, ждёт ответа, готов. Для Claude Code и Qwen Code точно, через хуки; для остальных по эвристике.Working, waiting, ready. Exact for Claude Code and Qwen Code via hooks; heuristics for the rest.

02 ♪

УведомленияNotifications

Системное уведомление и мягкий звук, когда агент закончил или ждёт вас. macOS и Linux.A system notification and a soft chime when an agent finishes or needs you. macOS and Linux.

03 ⎇

Git

Ветка и +/− у каждого агента, просмотр diff, commit, push, merge и worktree без выхода из Radar.Branch and +/− per agent, a diff viewer, commit, push, merge and worktrees without leaving Radar.

04 ⏻

Фоновые сессииBackground sessions

Закрыли окно, агенты работают дальше. Запустили radar и вернулись на тот же экран.Close the window and agents keep going. Run radar and you are back on the same screen.

05 y

Разрешения из спискаApprove from the list

Ответ на запрос агента одной клавишей, всегда с текстом запроса. Режима «разрешить всё» нет.Answer an agent's request with one key, always showing the request text. There is no "approve all".

06 >_

Управление из скриптовScriptable

radar ctl new / send / wait / read поднимает агентов и ждёт результата из любого скрипта.radar ctl new / send / wait / read starts agents and waits for results from any script.
