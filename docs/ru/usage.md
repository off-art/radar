# Работа в интерфейсе

[← README](../../README.md) · [English](../en/usage.md)

```sh
radar                        # открыть интерфейс, агентов добавлять клавишей n
radar ~/work/api claude      # открыть и сразу запустить Claude Code в папке
radar claude claude codex    # три агента в текущей папке
radar ~/work/api gigacode    # GigaCode CLI в папке проекта
```

Управление — **мышью** и **клавишами** (по модели Herdr).

## Мышь

- `ЛКМ` — выбрать агента; `+ новый` в шапке списка — запустить нового; `уведомления: вкл` внизу — переключатель.
- `ПКМ` (или Ctrl+клик) — контекстное меню: на агенте — переименовать, перезапустить, выключить уведомления только для него,
  новый агент в этой папке, закрыть; на пустом месте — новый агент, сетка, уведомления, помощь.
- Колесо — прокрутка истории. В `less`/`vim`/`htop` колесо работает как стрелки, а агентам, которые сами включили мышь
  (например OpenCode), события передаются как есть.
- Границу между списком и окном агента можно **потянуть** — ширина запоминается (от 20 колонок, окну агента остаётся не меньше 40).

## Клавиши

Нажмите **`Ctrl+b`** один раз — включится *режим навигации* (внизу жёлтая плашка «НАВИГАЦИЯ»). Ничего зажимать не нужно,
режим остаётся включённым, пока вы не нажмёте `Esc`/`Enter`.

| Клавиша | Действие |
|---|---|
| `j` / `k` (`↓` / `↑`, `Tab`, `(` `)`) | следующий / предыдущий агент |
| `1…9` | перейти к агенту по номеру |
| `n` / `N` | новый агент / новый агент того же типа в этой папке |
| `x` | закрыть агента |
| `r` / `R` | переименовать / перезапустить завершившегося |
| `w` | перейти к агенту, который **ждёт ответа** |
| `g` | сетка ⇄ один агент |
| `m` / `M` | тишина для выбранного агента / все уведомления |
| `u` `d` (`[` `]`, `PgUp` `PgDn`) | прокрутка истории |
| `y` | **разрешить запрос** агента, который ждёт ответа ([подробнее](git.md#разрешение-запросов-из-списка)) |
| `l` | **лента событий** ([подробнее](git.md#лента-событий)) |
| `v` | **изменения агента** (`git diff`) ([подробнее](git.md#просмотр-изменений-diff)) |
| `G` / `a` / `o` | создать группу / переместить агента в группу / свернуть-развернуть группу |
| `K` / `J` | переставить выбранного агента выше / ниже (порядок запоминается; то же — перетаскиванием и через ПКМ) |
| `,` | **настройки** (`Tab` — вкладка «Интеграции») |
| `S` | выбрать звуковую тему (с прослушиванием) |
| `p` или `Space` | **палитра команд** — поиск по действиям и агентам |
| `?` · `q` | помощь · выход |
| `Q` | остановить всех фоновых агентов и выйти |
| `Ctrl+b Ctrl+b` | отправить агенту сам `Ctrl+b` |

Без префикса работают `Shift+↑` / `Shift+↓` (переключение агентов) и `Shift+PgUp` / `Shift+PgDn` (прокрутка).
Все сочетания меняются в `[keys]` конфига ([Настройки](config.md)): можно сменить префикс (`ctrl+space`, `ctrl+a`…)
и добавить свои прямые сочетания (например `"alt+n" = "new"`). Пока агентов нет, `n`, `p`, `?`, `q` работают без префикса.

В формах и полях ввода работает обычное редактирование: `←/→`, `Home/End`, `Option+←/→`, `Ctrl+a/e/u/k/w`.

## Форма «Новый агент»

Показывает только установленные агенты (Radar проверяет это в фоне при запуске); кнопка `+ ещё N (не установлены)` показывает остальные.
Агента можно выбрать кликом, `←/→`, цифрой или `a` (показать/скрыть недоступных); клик по строке «Папка», «Имя» или по галочке
worktree переходит к ней. Между полями — `↑`/`↓` или клик. ПКМ на пустом месте тоже содержит пункты «Новый: <агент>» для каждого установленного агента.

- **Подсказка при наборе.** Пока вы печатаете путь, серым показывается первый подходящий вариант; `→` принимает его целиком.
- **Автодополнение папки.** `Tab` работает как в шелле: дописывает путь (`~/Desk` → `~/Desktop/`), при нескольких вариантах — общее начало
  и список под полем. Регистр не важен, `~/` можно не писать: `desk` + `Tab` → `~/Desktop/` (сначала ищется в текущей папке, затем в домашней).
  Скрытые папки подсказываются, если начать имя с точки.
- **Worktree.** Галочка создаёт для агента отдельный git worktree, чтобы несколько агентов не правили одни и те же файлы.

## Группы

Группы создаёте вы сами — автоматически агенты не группируются. Агенты без группы идут ниже всех групп под подписью «Без группы».

- **Создать** — кнопка `+ новая группа` внизу списка, `Ctrl+b`, `G` или ПКМ по пустому месту. В диалоге введите имя и отметьте агентов
  (`Tab` — переключиться между именем и списком, `Пробел` — отметить, `Enter` — готово). Можно создать **пустую** группу.
- **Добавить агента** — `Ctrl+b`, `a` (или ПКМ → «В группу…»); либо перетащить агента мышью на заголовок группы.
- **Переименовать, изменить состав, сдвинуть, удалить** — ПКМ по заголовку группы. При удалении агенты остаются в списке без группы.
- **Свернуть / развернуть** — клик по заголовку или `Ctrl+b`, `o`. В заголовке видна сводка: `▾ Бэкенд 3  ⠋ 1 ● 1 ✓ 1` (работают / ждут ответа / готовы).
- `K`/`J` переставляют агента только внутри его группы. Группы и свёрнутость запоминаются между запусками.

Во всех небольших окнах (подтверждения, диалог группы, переименование, палитра, разрешение запроса) работают клики:
по кнопкам `Enter` / `Esc`, по строкам списков и галочкам; клик мимо окна — отмена.

## Копирование текста

Протяните мышь с нажатой левой кнопкой по тексту в окне агента: выделение подсвечивается, а после отпускания текст
сразу копируется в буфер обмена (на macOS через `pbcopy`, иначе — через OSC 52). Внизу появится «Скопировано: N симв.».
Выделение работает и там, где агент сам ловит мышь (Qwen Code, OpenCode), и снимается любой клавишей, кликом или прокруткой.
Обычный клик по-прежнему уходит агенту. Выделение линейное, как в терминале; рамки агента (`│`) попадают в копию вместе с текстом.
Пока выделение на экране, ПКМ содержит пункт «Копировать».

Выключить: `Ctrl+b ,` → «Выделение мышью (копирование)» или `mouse_select = false` в `config.toml` — тогда мышь целиком уходит агенту
(нужно для vim, mc). Если выключить мышь совсем (`mouse = false`), работает родное выделение терминала. В обход Radar можно выделять
с зажатым Option (iTerm2) или Fn (Terminal.app), но так выделится и список агентов.
