## Почему задача

Текущий логотип (иконка `Radar.app` для уведомлений и картинка в README/GitHub) сделан по ходу работы,
без обсуждения вариантов и без выбора. Сейчас он нигде не зафиксирован как решение. Перед публичным
запуском (README с GIF, сайт, social preview) нужно выбрать осознанно.

## Что нужно решить

1. **Концепция.** Что должен передавать знак: радар/сканер, несколько «пинг-точек» (агентов), окно терминала, статусный индикатор?
   Варианты для обсуждения: (а) круг с лучом развёртки, (б) сетка точек разного цвета по статусам, (в) моноспейс-вордмарк `radar_` с курсором,
   (г) знак-скобки `[●]` из терминального мира.
2. **Форма применения.** Знак отдельно, вордмарк отдельно, или связка. Что остаётся читаемым в 16×16.
3. **Цвет.** Один акцент (сейчас оранжевый в бейдже релиза) или набор статусных цветов (работает / ждёт / готов). Совместимость со светлым и тёмным фоном.
4. **Где используется** (список для переделки после выбора):
   - иконка `~/.config/radar/Radar.app` в уведомлениях macOS (`assets/`);
   - шапка README (`README.md`, `README.en.md`);
   - GitHub social preview (1280×640) и аватар;
   - favicon и hero сайта (`docs/index.html`);
   - заставка / первый кадр GIF (`docs/demo.tape`);
   - при желании — ASCII-логотип в `radar --version` / `radar doctor`.
5. **Исходники.** Хранить SVG в репозитории (`assets/brand/`), растр генерировать скриптом, как звуки.
